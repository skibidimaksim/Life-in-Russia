# Life in Russia — Minecraft NeoForge 1.21.11
Version 0.1.0 — preliminary build. Player age starts at 14, advances by 1 every 10 minutes, resets after three deaths. Commands: /life get, /life set 18, /life add 10.

Extract this ZIP, then upload **the extracted folders and README.md** to the repository root (not the ZIP itself). GitHub Actions > Build Life in Russia > Run workflow. Download the artifact from a successful run. Java 21 and NeoForge 21.11.45 required.

This is a first prototype. The smartphone, Gosuslugi, taxes, military NPCs, age registration screen and adjustable config are not yet implemented. Compilation has not been tested locally.
